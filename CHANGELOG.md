# Changelog

All notable changes to this project. Newest first. Versions follow `MAJOR.MINOR.PATCH`
(semantic versioning: PATCH for fixes, MINOR for new features that break nothing, MAJOR for breaking changes).

## [1.1] - 2026-11-20

### Added
- `--sort mean|hottest|coldest|rainy|rain` orders the table, largest value first (#1).
- User guide, `docs/USER_GUIDE.md` (#2); revised as version 1.1 of the guide.
- Issue templates for user stories and bug reports.

## [1.0] - 2026-11-07

### Added
- First release: a year of weather per city, as a table and an HTML report.
